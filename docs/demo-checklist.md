# Demo 验收清单

基于门户标准模板，目标0.3.0。界面与竞争证据位于 `reports/2026-09-17-media/`；真实模型矩阵与线上回读分别归档，不将模拟权限测试当作实机兼容。

- [x] Demo 只服务当前 SDK 的单人人体关键点模型。
- [x] 默认文档语言为中文 `zh-CN`。
- [x] 页内中英文切换不重载模型状态。
- [x] 品牌栏包含名称、SDK版本、GitHub链接及双语切换；根README提供公开Demo链接。
- [x] 图片/视频/摄像头标签，共享三模型、双源、CPU/GPU与main/Worker；默认256×192 FP32、ModelScope、WASM、Worker。
- [x] 空预览没有破图。
- [x] 状态包含标准语义与可访问文本。
- [x] 折叠区显示模型身份、版本、字节数、官方参数量、精度、格式、来源、许可和 SHA-256。
- [x] 请求后端、实际后端、执行模式、运行时版本和当前桌面验证范围可见。
- [x] 下载、缓存读取、校验、会话、预处理、推理、后处理和总耗时可见。
- [x] 当前模型与本 SDK 全部缓存清理由用户触发并反馈结果。
- [x] 本地处理隐私说明可见。
- [x] 390px 视口无横向溢出，英文重置/运行按钮不重叠；这是桌面布局验收，不代表手机实测。
- [x] 视频首帧、播放/暂停、单帧、暂停定位、停止与损坏文件恢复。
- [x] 固定选框与清除不移动预览；采样帧和结果成对绘制。
- [x] 摄像头由用户触发且audio:false；拒绝、晚到授权、stop、隐藏、pagehide、配置变化和场景切换释放轨道。
- [x] 最大并发1、默认15FPS及5/10/15/30选项，处理/主动跳过计数、瞬时FPS、采集时间。
- [x] 正式构建真实12组合连续帧和默认配置的本地视频/fake-device摄像头通过；以 media-acceptance.json 为证。
- [x] 线上0.3.0页面回读、媒体基本流程和部署提交相符；见 `reports/2026-09-17-media/release/online-media.json`、`online-image.json` 与 `github-published.json`。

物理摄像头、手机、微信、NPU、自动多人和跟踪均不在本轮兼容声明内。
